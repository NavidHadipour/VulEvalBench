    Then balance what is left (optional)

    


    
    
      Drops from whichever label is over-represented until the two match.
      Without this, accuracy is read against whatever mix you keep — on
      a 70% vulnerable set, a detector that flags everything scores 0.70 and
      has detected nothing. Samples are generated independently, so the label
      mix is whatever the judges happened to admit; this is what evens it.
    

    
    
      Drops down to the smallest class, so the ranking is not mostly a
      ranking of whichever CWE happens to dominate. A class with only one of
      the two labels cannot be evened out and is dropped whole, by name.
    

    
      Ticking both targets a grid — every class the
      same size and even within itself. Classes alone can undo the
      label step, so doing both at once is not the same as doing them in
      sequence.
      Nothing is deleted: the generation, verified and selected manifests all
      survive, so the drop stays auditable, and the full composition report is
      printed to the log above either way.
