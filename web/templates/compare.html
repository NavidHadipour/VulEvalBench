How detectors are measured

Every detector answers the same two questions on the same verified samples — is this program vulnerable, and if so which CWE — so one scoring function evaluates all of them against the same ground truth. The numbers below are the standard measures derived from the confusion matrix:

  • TP / FP / FN / TN — the confusion matrix itself. Everything else is derived from these four counts.
  • Precision — of everything flagged, how much was really vulnerable. Recall — of everything really vulnerable, how much was caught. F1 is their harmonic mean.
  • FPR — the false-alarm rate on the safe twins. A detector that flags everything scores well on recall and is useless in practice; this is the column that exposes it.
  • MCC — a correlation over the whole confusion matrix, −1 to +1 with 0 meaning chance. Unlike accuracy it cannot be inflated by always answering with the majority class, which matters here because judging can leave the two classes uneven.
  • CWE id. — among the true positives, how often the tool also named the right category: whether it understood what the flaw was, not merely that something was wrong.

There is deliberately no combined score. An earlier version ranked tools by a weighted sum of F1, (1 − FPR) and CWE accuracy; it was removed because collapsing three different questions into one number hid which of them a tool actually failed, and the weights silently decided the ordering. Tables are sorted by F1 so they are stable and readable, but that is a sort order and not a score — read the whole row.
