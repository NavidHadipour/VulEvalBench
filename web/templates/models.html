Keys

Every API this installation can reach, in one file: {{ keys_file }}, which version control excludes. The names the shipped providers read are {% for name in reserved_entries %}{{ name }}{% if not loop.last %}, {% endif %}{% endfor %}; any other name carrying both a url and a key becomes a provider you can register models against, so a new API needs no code change.

Values are never shown. A key is displayed as its first and last few characters, which is enough to tell two keys apart and to match one against a provider’s console; a URL is shown in full because it is not a secret. To replace a key, save a new value under the same name and field — it overwrites in place.
